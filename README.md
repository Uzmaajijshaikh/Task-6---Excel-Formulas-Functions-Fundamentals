Data Analytics Internship – Task 6 (Excel Formulas & Functions Fundamentals)

This repository contains my submission for Task 6 of the Data Analytics Internship.

Dataset - Cleaned Sample Superstore Dataset

Objective - The objective was to practice commonly used Excel formulas and functions on a structured dataset and understand when to use each function.

Tools Used
1. Microsoft Excel
2. Sample Superstore Dataset
3. GitHub

Workbook Components
1. Raw Data sheet containing the cleaned Sample Superstore dataset
2. Formula Practice sheet containing examples of Excel formulas and functions
3. Notes sheet containing short explanations of when to use each function

Functions Demonstrated
1. VLOOKUP
2. INDEX/MATCH as an alternative to XLOOKUP
3. IF
4. SUMIFS
5. COUNTIFS
6. Text functions including LEFT, LEN, and UPPER

Analysis Performed
1. Used VLOOKUP to retrieve Sales based on a Sub-Category
2. Used INDEX/MATCH to demonstrate a lookup alternative to XLOOKUP
3. Used IF to classify transactions as Profit or Loss
4. Used SUMIFS to calculate Sales based on Category and Region
5. Used COUNTIFS to count transactions based on Category and Region
6. Used text functions to extract, count, and change text values
7. Tested an IF formula using a blank cell as an edge case

Excel Version Note - XLOOKUP is not available in Excel 2013. Therefore, INDEX/MATCH was used as the working alternative in the workbook.

Files
1. Task 6.xlsx - Excel workbook containing the formula practice and analysis
2. README.md - Summary of the Excel formulas and functions project

Conclusion - The Sample Superstore dataset was used to practice commonly used Excel formulas including VLOOKUP, INDEX/MATCH, IF, SUMIFS, COUNTIFS, and text functions. The task helped strengthen practical Excel skills and understanding of formulas used in everyday data analysis.
